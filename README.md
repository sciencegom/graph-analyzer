# ScienceGOM Graph Analyzer v0.3

그래프 이미지를 Google Gemini 멀티모달 모델로 표 데이터로 재구성하고, 확인한 표를 기존 데이터 분석에 연결합니다. Excel/Google Sheets 붙여넣기, 데모, 구간 드래그, ΔX·ΔY·단순 기울기·선형회귀·절편·R²·평균·표준편차·AUC, 비교 추가/삭제와 Y축 조정을 유지합니다.

## GitHub → Vercel 배포

1. 이 폴더 내용을 GitHub 저장소 루트에 올립니다.
2. Vercel에서 저장소를 Import합니다. Framework Preset은 Other로 선택하고 Build Command와 Output Directory는 별도로 지정하지 않습니다.
3. 서버 환경변수 `GEMINI_API_KEY`, `GEMINI_MODEL`, `ANALYZER_ACCESS_CODE`를 설정합니다. 모델은 Gemini API의 이미지 입력과 JSON 구조화 출력를 지원하는 사용 가능한 모델 ID를 넣습니다.
4. 배포합니다. 환경변수를 바꿨으면 재배포합니다.
5. 이미지 업로드 → 분석 이용 코드 입력 → 이미지→표 변환 → 곡선별 결과 확인 → 표 수정 → 데이터 분석으로 보내기 → 구간 드래그 → 비교 추가 순서로 사용합니다.

API 키는 화면이나 저장소에 넣지 않습니다. ANALYZER_ACCESS_CODE는 API 키와 다른, 사용자에게 제공할 이용 코드입니다. 서버 설정이 없으면 이미지 AI 변환은 503으로 차단되지만 기존 표 데이터 분석은 작동합니다. GitHub Pages만으로 서버 API를 실행할 수 없습니다.

## 로컬 실행

Node.js 22 이상에서 환경변수를 설정한 뒤 `npm start`로 실행합니다. 주소는 http://127.0.0.1:3000 입니다. 외부 패키지 설치는 필요하지 않습니다. `.env.example`은 설정 이름 안내이며 서버가 .env를 자동으로 읽지는 않습니다. `node --env-file=.env server.mjs`를 사용할 수 있습니다. 검사는 `npm test`입니다.

## 정확도와 운영 범위

현재 방식은 AI가 축·범례를 읽고 곡선별 약 20–60개 좌표를 추정합니다. 원본 센서 데이터 복원이나 픽셀 기반 정밀 곡선 추출을 보장하지 않습니다. 재구성 그래프와 표를 원본과 비교하고 필요하면 표를 수정하세요. R²와 AUC는 추정 좌표에서 계산되며 표본 수는 원본 측정 횟수가 아닙니다. 겹친 곡선, 작은 축 글자, 로그 축 등은 결과를 특히 확인하세요.

서버는 요청 크기 제한, 이용 코드 인증, 출력 형식·숫자·중복 X좌표 검사, 타임아웃을 적용합니다. 공개 운영 전에 사용자별 로그인, 영속적인 호출 횟수 제한과 비용 통제를 추가해야 합니다. 이용 코드는 메모리에만 입력되며 브라우저 저장소에 보관하지 않습니다. 이미지는 변환 버튼을 누를 때 Google Gemini로 전송되며 서버는 자체 파일 저장을 하지 않고 Gemini의 데이터 처리 정책이 적용됩니다. 이것이 제공자의 모든 보존 정책을 없애는 것은 아닙니다.

## 검증 상태

자동 검사: 표 데이터 계산과 파싱 회귀 검사, AI 출력 검증, 서버 미설정 차단.
실제 Google Gemini 변환은 키·모델 설정 후 확인해야 합니다. 이전 브라우저 검증은 로컬 파일 URL 정책으로 차단되어 실제 마우스·클립보드 검증이 완료되지 않았습니다.


## 키와 모델 저장 위치

Google AI Studio https://aistudio.google.com/api-keys 에서 Gemini API 키를 발급합니다. Vercel에서 이 저장소를 Import하고 프로젝트 Settings → Environment Variables에 다음 세 값을 저장합니다.

| 이름 | 값 |
| --- | --- |
| GEMINI_API_KEY | Google AI Studio에서 발급한 실제 API 키 |
| GEMINI_MODEL | 이미지 입력·JSON 구조화 출력을 지원하고 해당 키로 이용 가능한 모델 ID (models/ 접두어 제외) |
| ANALYZER_ACCESS_CODE | 직접 정한 별도의 충분히 긴 이용 코드 |

Production 환경을 선택하고 저장한 뒤 Deployments → Redeploy를 실행합니다. Preview 환경에서도 테스트하려면 해당 환경에도 설정합니다. 키는 GitHub 파일·웹 화면·채팅에 입력하지 않습니다. 기존 OPENAI_API_KEY와 OPENAI_MODEL은 이 코드에서 사용하지 않으므로 삭제할 수 있습니다. 분석 이용 코드는 API 키가 아니며 사이트의 이미지 분석 화면에 입력합니다.

배포 후 데모 데이터와 붙여넣기 분석을 먼저 확인하고, 축이 선명한 그래프를 업로드한 뒤 이용 코드를 입력해 변환합니다. 결과에서 축·단위·곡선 모양을 확인하고 표를 데이터 분석으로 보낸 뒤 구간 드래그와 비교 추가를 확인합니다. 설정 오류는 변수 이름·Production 선택·모델 접근 권한·재배포를 확인합니다. 429 오류는 Google API 할당량과 결제 상태를 확인합니다. 실제 Gemini 응답 품질 검증은 유효한 키와 모델을 설정한 뒤 필요합니다.
