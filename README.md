# ScienceGOM Graph Analyzer v0.3

그래프 이미지를 OpenAI 멀티모달 모델로 표 데이터로 재구성하고, 확인한 표를 기존 데이터 분석에 연결합니다. Excel/Google Sheets 붙여넣기, 데모, 구간 드래그, ΔX·ΔY·단순 기울기·선형회귀·절편·R²·평균·표준편차·AUC, 비교 추가/삭제와 Y축 조정을 유지합니다.

## GitHub → Vercel 배포

1. 이 폴더 내용을 GitHub 저장소 루트에 올립니다.
2. Vercel에서 저장소를 Import합니다. Framework Preset은 Other로 선택하고 Build Command와 Output Directory는 별도로 지정하지 않습니다.
3. 서버 환경변수 `OPENAI_API_KEY`, `OPENAI_MODEL`, `ANALYZER_ACCESS_CODE`를 설정합니다. 모델은 Responses API의 이미지 입력과 JSON Schema Structured Outputs를 지원하는 사용 가능한 모델 ID를 넣습니다.
4. 배포합니다. 환경변수를 바꿨으면 재배포합니다.
5. 이미지 업로드 → 분석 이용 코드 입력 → 이미지→표 변환 → 곡선별 결과 확인 → 표 수정 → 데이터 분석으로 보내기 → 구간 드래그 → 비교 추가 순서로 사용합니다.

API 키는 화면이나 저장소에 넣지 않습니다. ANALYZER_ACCESS_CODE는 API 키와 다른, 사용자에게 제공할 이용 코드입니다. 서버 설정이 없으면 이미지 AI 변환은 503으로 차단되지만 기존 표 데이터 분석은 작동합니다. GitHub Pages만으로 서버 API를 실행할 수 없습니다.

## 로컬 실행

Node.js 22 이상에서 환경변수를 설정한 뒤 `npm start`로 실행합니다. 주소는 http://127.0.0.1:3000 입니다. 외부 패키지 설치는 필요하지 않습니다. `.env.example`은 설정 이름 안내이며 서버가 .env를 자동으로 읽지는 않습니다. `node --env-file=.env server.mjs`를 사용할 수 있습니다. 검사는 `npm test`입니다.

## 정확도와 운영 범위

현재 방식은 AI가 축·범례를 읽고 곡선별 약 20–60개 좌표를 추정합니다. 원본 센서 데이터 복원이나 픽셀 기반 정밀 곡선 추출을 보장하지 않습니다. 재구성 그래프와 표를 원본과 비교하고 필요하면 표를 수정하세요. R²와 AUC는 추정 좌표에서 계산되며 표본 수는 원본 측정 횟수가 아닙니다. 겹친 곡선, 작은 축 글자, 로그 축 등은 결과를 특히 확인하세요.

서버는 요청 크기 제한, 이용 코드 인증, 출력 형식·숫자·중복 X좌표 검사, 타임아웃을 적용합니다. 공개 운영 전에 사용자별 로그인, 영속적인 호출 횟수 제한과 비용 통제를 추가해야 합니다. 이용 코드는 메모리에만 입력되며 브라우저 저장소에 보관하지 않습니다. 이미지는 변환 버튼을 누를 때 OpenAI로 전송되며 서버는 자체 파일 저장을 하지 않고 API 요청에 store:false를 사용합니다. 이것이 제공자의 모든 보존 정책을 없애는 것은 아닙니다.

## 검증 상태

자동 검사: 표 데이터 계산과 파싱 회귀 검사, AI 출력 검증, 서버 미설정 차단.
실제 OpenAI 변환은 키·모델 설정 후 확인해야 합니다. 이전 브라우저 검증은 로컬 파일 URL 정책으로 차단되어 실제 마우스·클립보드 검증이 완료되지 않았습니다.
